# Updates made for the empirical study of mid-workflow changes

Changes relative to the original MA-Gym code, grouped by component. The current direction is an **empirical study of how a manager agent handles environmental, preference and
goal changes, run on MA-Gym's benchmarks improved with other peer-reviewed benchmarks** (design in [`research/decisions.md`](research/decisions.md) D21 to D28, proposal in [`research/Project Proposal.md`](research/Project%20Proposal.md), open items in [`research/preregistration.md`](research/preregistration.md)).
Status is **Done** (in the working tree) or **Planned** (decided, not built).
On 2026-11-03 the docs were rewritten for this direction, the Planned rows of the retired agent-loss benchmark were deleted, and the code the study does not need was removed: the agent-unavailability hooks
(`unavailable_agents`, `_can_start`, the availability notice block), the join/leave team-change metrics with their CLI, test and dashboard cards, and the unused scripts (list in [`DEV.md`](DEV.md)).
The goal is the original MA-Gym code plus core logic changes and bug fixes.
